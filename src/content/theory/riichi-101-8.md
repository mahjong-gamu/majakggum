리치 마작의 역을 **울었을 때(멘젠이 깨졌을 때)** 어떻게 되는지에 따라 네 묶음으로 나눴습니다. 처음부터 다 외울 필요는 없습니다. 기초 역은 [⑤편](/theory/riichi-101-5/)을 먼저 봐 주세요.

## 멘젠 한정

**멘젠일 때만** 성립하는 역입니다. 울면 이 역들은 사라집니다.

| 역 | 판 | 조건 | 예시 |
| --- | --- | --- | --- |
| 리치 | 1 | 텐파이 상태에서 리치를 선언하고 1,000점을 공탁 | |
| 일발 | 1 | 리치 선언 후, 아무도 울지 않은 1순 이내에 화료 | |
| 멘젠쯔모 | 1 | 쯔모로 화료 | |
| 핑후 | 1 | 머리가 역패가 아니고, 몸통이 모두 슌쯔이며, 양면 대기 | |
| 이페코 | 1 | 똑같은 슌쯔가 2개 | `223344m` |
| 더블 리치 | 2 | 아무도 울지 않은 첫 순(첫 버림패)에 리치 | |
| 치또이 | 2 | 머리 7개 | `113355m 2266p 7799s` |
| 양페코 | 3 | 이페코가 2개 | `223344m 667788p` |

## 멘젠 준한정

울어도 성립하지만, 울면 **판수가 1판 줄어드는** 역입니다.

| 역 | 판 (울면) | 조건 | 예시 |
| --- | --- | --- | --- |
| 삼색동순 | 2 (1) | 만수·통수·삭수로 같은 숫자의 슌쯔 | `345m345p345s` |
| 일기통관 | 2 (1) | 같은 종류의 수패로 123·456·789 | `123456789p` |
| 찬타 | 2 (1) | 모든 몸통과 머리에 요구패가 포함 | `123m 789p 999s 111z 99m` |
| 혼일색 | 3 (2) | 한 종류의 수패와 자패만으로 모든 몸통과 머리 | `123s 345s 777s 555z 99s` |
| 준찬타 | 3 (2) | 모든 몸통과 머리에 노두패가 포함 (자패 없이) | `123m 789p 999s 789s 11p` |
| 청일색 | 6 (5) | 한 종류의 수패만으로 모든 몸통과 머리 | `112233p 456p 678p 99p` |

## 멘젠 비한정

울어도 **판수 그대로** 성립하는 역입니다.

| 역 | 판 | 조건 | 예시 |
| --- | --- | --- | --- |
| 역패 | 1 | 역패(삼원패·장풍패·자풍패)를 몸통으로 | `777z` |
| 탕야오 | 1 | 중장패(2~8)로만 모든 몸통과 머리 | `234m 567p 345s 666s 88p` |
| 해저로월 | 1 | 패산의 마지막 패(해저패)를 쯔모해 화료 | |
| 하저로어 | 1 | 마지막 버림패(하저패)를 론해 화료 | |
| 창깡 | 1 | 다른 사람이 가깡(소명깡)하는 패를 론해 화료 | |
| 영상개화 | 1 | 깡을 한 뒤 쯔모한 영상패로 화료 | |
| 또이또이 | 2 | 모든 몸통이 커쯔 | `222m 777p 333s 666z 99m` |
| 산안커 | 2 | 안커 3개를 포함 | |
| 삼색동각 | 2 | 만수·통수·삭수로 같은 숫자의 커쯔 | `555m555p555s` |
| 산깡쯔 | 2 | 깡쯔 3개를 포함 | |
| 소삼원 | 2 | 삼원패 3종 중 2종은 몸통, 1종은 머리 | `555z 666z 77z` |
| 혼노두 | 2 | 노두패와 자패만으로 모든 몸통과 머리 | `111m 999p 999s 222z 77z` |

## 역만

| 역 | 조건 | 예시 |
| --- | --- | --- |
| 국사무쌍 | 요구패 13종을 1장씩, 아무 요구패 1장 더 | `19m19p19s1234567z 1z` |
| 스안커 | 몸통을 모두 안커로 | |
| 대삼원 | 삼원패 3종을 모두 몸통으로 | `555z 666z 777z` |
| 녹일색 | 삭수 2·3·4·6·8과 발로만 모든 머리와 몸통 | `234s 666s 888s 666z 22s` |
| 자일색 | 자패로만 모든 머리와 몸통 | `111z 333z 555z 777z 22z` |
| 사희화 | 풍패 중 3종은 몸통·1종은 머리(소사희), 또는 4종 모두 몸통(대사희) | `111z 222z 333z 44z` |
| 청노두 | 노두패로만 모든 머리와 몸통 | `111m 999m 111p 999s 11s` |
| 스깡쯔 | 깡쯔 4개 | |
| 구련보등 | 한 종류의 수패로 1112345678999 + 아무 패 1장 | `1112345678999m 5m` |
| 천화 | 오야가 배패를 받자마자 화료 | |
| 지화 | 자가 아무도 울지 않은 첫 쯔모로 화료 | |

- 역만은 판수를 세지 않고 바로 **역만 점수**(자 32,000 / 오야 48,000)가 됩니다.
- 역만이 2개 이상 겹치면 **더블 역만**처럼 배수로 계산합니다. 점수는 [⑦편](/theory/riichi-101-7/)을 참고하세요.
